========================================
 Nuclear Option《核选项》简体中文汉化 v1.3.0
 适用版本：Nuclear Option 0.34.6（Steam）
========================================

一、这是什么
----------------------------------------
《Nuclear Option》的完整简体中文化补丁。

它不修改游戏的任何原始文件，而是通过 BepInEx 在启动时注入一个轻量汉化插件：
  · 词典精确匹配：只替换命中词条的文本，不做全场景扫描、不跑逐帧正则、不联网；
  · 字体方案：保留游戏原版拉丁字体，中文自动用系统字体（微软雅黑）按需渲染，
    不替换字体贴图，也不改原有排版；
  · 语言文件是纯文本（zh_cn.tsv），随时可改，游戏内按 F10 热重载。

二、安装
----------------------------------------
  把整个压缩包解压到任意位置，双击 install.bat 即可。
  安装程序会自动从注册表和 Steam 库配置里找游戏目录；
  找不到时会让你把游戏文件夹拖进来。

  安装完成后直接启动游戏，界面就是中文了。

  如果杀毒软件拦 winhttp.dll：这是 BepInEx 的注入器，属于正常工具，
  加白名单即可。

三、卸载
----------------------------------------
  双击 uninstall.bat。

  卸载会：删除汉化插件与语言文件；
          如果 BepInEx 下没有别的插件，连 BepInEx 一起删干净；
          然后自动调用 Steam 的「验证游戏文件完整性」，把可能的残留清掉。

四、配置
----------------------------------------
  配置文件：BepInEx\plugins\NuclearOptionCn\config.ini

  enable      = true       是否启用汉化（false 可临时关掉，不用卸载）
  font_mode   = fallback   字体模式：
                             fallback   = 保留原版字体，中文用回退字体（推荐，最接近原版）
                             translated = 只有被翻译的文本用中文字体
                             unified    = 全部文本统一用中文字体
  sweep       = false      补译扫描（遍历场景里所有文本组件）。
                             默认关闭：实测开启后会在主菜单卡顿甚至导致游戏退出。
                             只有在发现某处静态文本死活不翻时才建议打开排查。
  debug_fps   = false      每 5 秒把帧率写进 BepInEx\LogOutput.log

五、热重载
----------------------------------------
  游戏内按 F10，会重新读取 zh_cn.tsv，不用重启。
  （dll 的更新仍然需要重启游戏。）

六、做了什么（v1.3.0）
----------------------------------------
  · 词表 8,213 条，覆盖：主菜单、设置全部页签、按键绑定、百科（飞机/载具/舰船/
    建筑/导弹全部条目与参数）、任务编辑器全部面板、任务选择与任务说明、
    多人服务器列表、出击/挂载/涂装界面、任务内 HUD 与告警、98 条「你知道吗」
    小知识、教程对话、任务脚本消息。
  · 单位俗名统一音译：亥伯龙级、阿格斯级、迪纳摩级、安纳克斯级、库尔索级、
    沙德级、冲浪级；机型绰号：蟋蟀、罗盘、狼蛛、美杜莎、急弯、伊夫利特、
    斗士、镰刀、弯刀、枢纽、主销、铁砧、剥夺者、后坐、螺旋钻、朱鹮、折刀、
    雷击、流浪者、精灵、眼球、暗域、涡流、翠鸟。
  · 弹药与挂架全量翻译（含 AGM/ALM/ARAD/AShM/GPO/PAB/IRM/MMR/RAM 系列）。
  · 涂装名全量翻译，工坊涂装保留作者名并加注「（创意工坊）」。
  · 支持带格式说明符的模板（{0:F2} 等）、按键占位（<bind=...>）、
    名称+数量/距离、多行提示框逐行翻译。

七、已知限制
----------------------------------------
  · 任务缩略图里烙死的英文标题（missionimages/*.png）无法翻译；
  · 部分纯内部标识符（如 Aircraft.RpcEscapeCapsule）刻意不译；
  · 摇杆/头瞄等硬件产品名（Thrustmaster T.16000M 等）保留原文；
  · 玩家名、服务器名、工坊涂装作者名保持原样。
