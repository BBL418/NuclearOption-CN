# Nuclear Option 汉化术语与规则（所有译者必须遵守）

## 背景
《Nuclear Option》（核选项）是一款现代军事飞行模拟/空战游戏，含冷战至近未来战机、舰船、地面部队、核武器。
汉化对象是游戏 UI 与百科文本。玩家是军事模拟爱好者，翻译要专业、简洁、像军事手册，不要口语化、不要机翻腔。

## 风格要求
- 简洁、直接、专业。按钮类尽量 2-6 个汉字。
- 全角标点：中文句子用「，。：；！？（）」，但以下保持半角：数字、单位、型号、占位符、标签。
- 不要在中文里加多余空格；中英混排时英文两侧留一个空格（如「F-16 战斗机」）。
- 不翻译：飞机/武器/舰船的型号代号（F-16、Su-27、AGM-88、AIM-120、EW-25、SFB-81、T/A-30、CI-22 等），但型号后的英文绰号可音译或保留（如 "Vortex"→"涡流"、"Compass"→"罗盘"，首次出现可写「Vortex 涡流」）。
- 缩写保留英文大写：HUD、MFD、RWR、ECM、IRST、SAM、SEAD、CAS、CAP、TGP、AOA、RCS、VTOL、STOVL、IR、TV、GPS、IFF、AGL、MSL、AAM、AGM、ASM、ATGM、SPAA、CIWS、VLS、TWR、SMS、EW、NBC。
- 游戏内专有名词：Faction→阵营；Sortie→出击；Loadout→挂载；Hardpoint/Pylon→挂点；Squadron→中队；Airbase→空军基地；Carrier→航空母舰。

## 占位符与标记规则（极其重要）
1. 保留所有 `{0}` `{1}` `{2:0.0}` `{0:F0}` 等占位符，原样不动，可以调整它们在句中的位置。
2. 保留所有富文本标签原样：`<color=#RRGGBB>`、`</color>`、`<b>`、`</b>`、`<i>`、`<size=70%>`、`</size>`、`<sprite=..>`、`<link=..>`、`<br>`。
3. 文本中的 `\n` 是换行转义，必须原样保留，数量与位置尽量一致。
4. 保留首尾空格（有些 UI 靠空格排版）。
5. 数字、单位（km/h、m、t、kt、nm、mm、%）、型号不改。
6. 若原字符串只是型号/代号/缩写/纯数字（如 `AIM-120`、`HUD`、`12:34`），原样输出。
7. 若原字符串是 `KEY: value` 形式，中文用全角冒号：`键：值`（但保留 `{0}`）。
8. 不要添加原文没有的解释、括号注释或标点。

## 输出格式
逐行输出，每条一行：`编号<TAB>译文`，编号与输入一致，不得缺行、不得合并、不得加序号外的内容。
译文中的换行用字面 `\n`（反斜杠+n）表示，与原文一致。

## 特殊条目
9. 若原文已经包含中文（说明它已是译文），原样输出，不要改写。
10. 若原文只有空白字符、零宽字符（如 U+200B）、纯符号或无实义字符，则译文输出为空（即只写「编号<TAB>」后直接换行）。
11. 若原文是调试/日志/内部错误信息（读起来像程序日志），仍然翻译，但保持技术中性。
